# 外部绘制 · GAME-OVERLAY

类目：游戏工具（`GAME-TOOL-3`）　关键词：外部绘制 Overlay 不过检测 独立窗口

选技术：透明窗口 + 桌面合成、DWM 共享纹理、采集卡 / 独立设备。

解决性能与同步：帧率、读屏延迟、窗口置顶与穿透。

交可运行的外部绘制单元；对比各方案在检测面与稳定性上的差异。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`

命令一律给 PowerShell / pwsh 形式（这台机器是 Windows），不交 bash / Linux 写法。
