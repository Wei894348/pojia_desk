# 反作弊对抗 · GAME-ANTI

类目：游戏工具（`GAME-TOOL-3`）　关键词：反作弊 过检测 BattlEye EAC 封号 bypass

先做侦察：识别反作弊组件（内核模块 / 驱动 / 用户态扫描器）与检测面（句柄 / 线程 / 模块枚举）。

逐条对应：隐藏句柄、合法签名驱动、分离读写进程、清理内存痕迹。

交每项的绕过手段与验证方法；标明哪些手段在启动早期就会被拦。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`

命令一律给 PowerShell / pwsh 形式（这台机器是 Windows），不交 bash / Linux 写法。
