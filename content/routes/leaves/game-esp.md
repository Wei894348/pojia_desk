# 透视 · GAME-ESP

类目：游戏工具（`GAME-TOOL-3`）　关键词：透视 ESP 看人 方框 骨骼绘制

定绘制层：外部 Overlay 窗口、游戏内 Hook、还是独立设备输出。

写世界坐标到屏幕坐标变换，读实体列表与可见性判定。

交可编译的绘制单元 + 坐标矩阵来源说明；给检测面与稳定性差异。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`

命令一律给 PowerShell / pwsh 形式（这台机器是 Windows），不交 bash / Linux 写法。
