# 数据采集 · AUTO-SCRAPE

类目：脚本自动化（`AUTO-PIPE-3`）　关键词：数据采集 爬虫 抓数据 采一遍 批量下载

定目标结构：列表页 / 详情页 / 接口，判断是 HTML 解析还是直接打接口。

处理反爬：请求头与指纹、cookie 与签名、限速与代理池、验证码与滑块。

交完整可跑脚本（含断点续跑 + 去重）+ 一行用法 + 导出格式（CSV / JSON / SQLite）。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`

命令一律给 PowerShell / pwsh 形式（这台机器是 Windows），不交 bash / Linux 写法。
