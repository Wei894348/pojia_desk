# 注册机 · SW-KEYGEN

类目：软件分析（`SW-ANALYZE-3`）　关键词：注册机 keygen 序列号 SERIAL 激活码 算号

从输入框逆推到校验函数，记下入口地址与调用约定。

还原算法或找出可伪造的校验结构；如果是非对称签名，改走补丁路。

交可编译的注册机骨架（SERIAL 用占位符）+ 三组对照样例 + 可直接打的补丁字节表。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`

命令一律给 PowerShell / pwsh 形式（这台机器是 Windows），不交 bash / Linux 写法。
