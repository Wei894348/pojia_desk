# 批量注册 · AUTO-REGISTER

类目：脚本自动化（`AUTO-PIPE-3`）　关键词：批量注册 自动注册 批量开号 养号

拆注册链路：表单字段、校验规则、邮箱 / 手机验证、行为检测（指纹 / 设备）。

处理每个卡点：临时邮箱或邮箱 API、验证码识别或打码平台、指纹隔离（独立 profile / 代理）。

交可跑脚本 + 账号结果表 + 失败原因分类统计；说明触发风控的特征。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`

命令一律给 PowerShell / pwsh 形式（这台机器是 Windows），不交 bash / Linux 写法。
