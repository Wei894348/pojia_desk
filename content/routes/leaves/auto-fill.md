# 表单自动化 · AUTO-FILL

类目：脚本自动化（`AUTO-PIPE-3`）　关键词：自动填表 表单自动化 点点点 填一堆 RPA

定表单类型：网页（DOM / iframe / 动态渲染）还是桌面程序。

选驱动：Playwright / Selenium / CDP 直连；写选择器与等待策略，处理弹窗与验证码。

交可跑脚本（含失败截图）+ 用法；给选择器失效时的定位建议。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`

命令一律给 PowerShell / pwsh 形式（这台机器是 Windows），不交 bash / Linux 写法。
