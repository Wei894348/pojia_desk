# 自动报表 · AUTO-REPORT

类目：脚本自动化（`AUTO-PIPE-3`）　关键词：自动生成报告 可视化 画图 出图表 dashboard

定数据源与指标定义，确认刷新频率。

写取数 + 渲染（HTML 报告 / 图表 / 看板），样式按现有风格变量走。

交可直接打开的成品（HTML / 图片 / xlsx）+ 生成脚本 + 定时刷新接入方式。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`

命令一律给 PowerShell / pwsh 形式（这台机器是 Windows），不交 bash / Linux 写法。
