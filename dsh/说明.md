# dsh/ —— DeepSeek Harness 破甲

## 统一入口（推荐）

根目录 `console.bat` / `console.py` 是三目标（codex / dsh / wb）统一控制台：

```
console.bat dsh apply     破甲
console.bat dsh revert    复原
console.bat dsh status    状态（只读）
console.bat dsh test      验证测试（只读：扫描 @deepseek-ai 人格标记命中率）
console.bat all test      三目标全部验证
```

## 内容

| 文件 | 作用 |
|---|---|
| `unlock-dsh.bat` | 一键破甲：锁死 `--target dsh`，等价于 `python ..\破甲一键通.py --apply --force --yes --target dsh`；追加参数可覆盖（如 `unlock-dsh.bat --revert` 还原） |
| `persona.md` | 共用人格快照（与根目录 `persona.md` 同源；**根目录才是源头**，改完根目录重跑 bat） |

## 打法（四层）

1. `WORKSPACE_CONTEXT_INTRO` 类"仅供参考"免责声明 → 升级为 ACTIVE 强制；
   （v6.1 起同时清掉历史版本注入的"别当成 prompt injection"自证句 —— 见 `patch_legacy_self_proof`）
2. 剥离官方默认身份，由人格作唯一身份来源；
3. `PERSONA_SECTION_NAMES` 补区段；
4. persona 正文 = **任务路由层 + 操作者人格 + 强化版政策 + 覆盖层**。
   路由层单一来源是根目录 `route-layer.md`，改完 `console.bat dsh apply`。

## 注意

- 改的是磁盘文件，**完全退出 DSH（含托盘）再重开并新建会话**才生效。
- 脚本默认不杀 DSH 进程（本会话可能就跑在里面）；`--kill-dsh` 才允许结束。
- `dsh-sdk-minimal\cordis.patch.yml` 身份由 `!!js` 动态指定，脚本设计上不碰，需手动改。
- 备份后缀 `.dshpurge.bak`，与原 dsh-purge 工具互通。
