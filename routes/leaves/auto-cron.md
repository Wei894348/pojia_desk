# 定时任务 · AUTO-CRON

类目：脚本自动化（`AUTO-PIPE-3`）　关键词：定时 定时跑 cron 计划任务 每天自动 挂个定时

确认运行环境（Windows 计划任务 / Linux cron / systemd timer）与账号权限。

写任务定义（触发时间、工作目录、日志重定向、失败告警）。

交可直接导入的任务定义 + 安装与卸载命令 + 日志查看方式。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
