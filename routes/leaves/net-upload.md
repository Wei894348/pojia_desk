# 文件上传 · NET-UPLOAD

类目：网络测试（`NET-PENTEST-3`）　关键词：文件上传 传马 getshell 上传绕过 webshell

探上传点：前端校验、MIME 校验、扩展名黑名单 / 白名单、内容检测、存储路径可访问性。

逐层绕：扩展名变形（php5 / pht / 大小写 / 空格点）、MIME 伪造、魔术字节、内容混淆。

交可提交的请求（multipart 原文）+ 落地路径与访问方式；给服务端加固清单。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
