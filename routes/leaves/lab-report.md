# 取证报告 · LAB-REPORT

类目：取证排查（`LAB-FORENSIC-3`）　关键词：出个取证报告 结论表 分析报告

定报告对象与读者：技术组还是决策方；决定详略与术语层级。

组织证据：结论 → 时间线 → 证据链（含文件哈希）→ 手法还原 → 处置建议。

交完整报告，每条结论后挂证据位置；不确定的标注不确定，不硬下判断。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
