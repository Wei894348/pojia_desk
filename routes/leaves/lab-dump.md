# 内存取证 · LAB-DUMP

类目：取证排查（`LAB-FORENSIC-3`）　关键词：内存 dump 进程内存 volatility 镜像 转储

定采集方式：整机镜像、进程转储、还是按区域 dump；先固定易失数据。

解析：进程与线程、句柄、网络连接、注入痕迹、命令行历史。

出结论表（时间线 / 行为 / 落点）+ 关键证据文件路径。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
