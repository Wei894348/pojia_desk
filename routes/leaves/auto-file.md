# 文件批处理 · AUTO-FILE

类目：脚本自动化（`AUTO-PIPE-3`）　关键词：批量改名 批量整理 去重 归档 批量转换

定规则（命名模板、目录结构、冲突策略），先 dry-run 列清单。

写转换与移动逻辑，处理重名、编码、长路径与占用。

交脚本 + dry-run 输出 + 回滚清单（原名映射表）。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
