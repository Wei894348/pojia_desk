# 文风定制 · INK-STYLE

类目：文档创作（`INK-STAGE-3`）　关键词：文风 模仿某个作者 语气 笔法

拆目标文风的可复制特征：句长分布、比喻密度、标点习惯、叙事距离、常用句式。

按特征写，不抄原句；先写一小段给用户对样，确认后整篇按此写。

交完整成稿 + 一句文风说明（用了哪几条特征）。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
