# 剧本 · INK-SCRIPT

类目：文档创作（`INK-STAGE-3`）　关键词：剧本 台本 分镜 场次 台词本

定格式（影视 / 舞台 / 短剧 / 分镜），按格式给场次头（时间、地点、内外景）。

动作行写可拍的内容，对白写人物能说出口的话；节奏按场次功能排。

交完整场次，含转场与音效提示；不写「此处略」，不加旁白解释。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
