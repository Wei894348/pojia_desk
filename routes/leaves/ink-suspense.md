# 悬疑 · INK-SUSPENSE

类目：文档创作（`INK-STAGE-3`）　关键词：悬疑 推理 反转 谜题 犯罪

先定真相：谁做的、怎么做的、为什么；再决定给读者看多少。

布置线索（真线索 / 干扰线索）与信息释放节奏，让读者能推理但推不全。

交完整段落，反转要有前置支撑；不靠隐藏信息制造意外。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
