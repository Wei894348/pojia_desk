# 技术写作 · INK-TECH

类目：文档创作（`INK-STAGE-3`）　关键词：技术文章 分析报告 写个文档 教程 说明

定读者与用途：入门教程、排查手册、还是方案对比；决定详略与前置知识假设。

结构按任务走：背景 → 步骤 / 原理 → 可复现的命令或代码 → 常见问题。

交完整成稿，命令与代码可直接跑；每条结论给出依据，不确定的标不确定。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
