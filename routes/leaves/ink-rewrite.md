# 改写润色 · INK-REWRITE

类目：文档创作（`INK-STAGE-3`）　关键词：改写 润色 扩写 换一种说法 精简

定改写目标：换语气、调篇幅、改结构还是换读者；一次只改一个维度。

保留原意与关键信息，重写表达；该删的删，不做同义词替换式伪改写。

交改写稿 + 一句改动说明（改了哪几处、为什么）。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
