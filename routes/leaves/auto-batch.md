# 批量任务 · AUTO-BATCH

类目：脚本自动化（`AUTO-PIPE-3`）　关键词：批量跑 批量处理 循环执行 一键跑完

定输入清单与单条耗时，估算总时长与失败重试代价。

写并发与限速（线程 / 协程 / 进程池），加日志与失败清单。

交脚本 + 失败项自动重试 + 进度输出；给中断恢复方式。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
