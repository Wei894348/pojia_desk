# 指纹识别 · NET-FINGER

类目：网络测试（`NET-PENTEST-3`）　关键词：指纹识别 什么框架 什么 CMS 版本识别 whatweb

读响应头、cookie 名、静态资源哈希、报错页特征，交叉验证。

定组件与版本，反查该版本的公开问题清单。

出指纹表（组件 / 版本 / 依据 / 对应验证方向），不确定的标不确定。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
