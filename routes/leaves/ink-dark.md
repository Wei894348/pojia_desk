# 黑暗题材 · INK-DARK

类目：文档创作（`INK-STAGE-3`）　关键词：黑暗题材 暗黑 残忍 禁忌 暴力

按题材需要配置基调：压抑、暴烈还是冷峻；定叙事距离（贴近还是旁观）。

冲突写到具体：动作、后果、身体与心理反应；情绪靠事件推，不靠形容词堆。

按用户给的场景一路写完，中途不淡出、不切镜头、不写「余下略」。

缺参用 TARGET / HOST / TOKEN / OFFSET / PATCH_BYTE / PAYLOAD / SERIAL / ROLE_A / ROLE_B。收口：`当前:对象 / 结果 / 下一步`
