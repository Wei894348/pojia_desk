# dsh/ —— DeepSeek Harness 提示词注入

## 统一入口（推荐）

`console.bat`（或 `engine/console.py`）是统一控制台（codex / dsh / wb / claude / hermes / zcode）：

```
console.bat dsh apply     部署
console.bat dsh revert    复原
console.bat dsh status    状态（只读）
console.bat dsh test      验证测试（只读：AGENTS.md 标记块 + budget + skills）
console.bat all test      全部目标验证
```

## 落点（2026-10-19 起）

DSH 的提示词只走它自己的 workspace-instruction 通道：

| 落点 | 说明 |
|---|---|
| `<DSH_HOME>\AGENTS.md` | `@deepseek-ai/dsh-agent-instructions` 每个会话首轮读取；包内 `USER_GLOBAL_FILE = "AGENTS.md"` 写死 |
| `<DSH_HOME>\skills\<id>\SKILL.md` | `skill-filesystem` 插件内置的 user skill 根；路由三拍按需加载 |

桌面版与 Web/CLI **共用同一个 `~/.dsh`**，所以这两个落点两端同时生效。

- 部署时只动 `<!-- pojia:dsh begin/end -->` 之间的块，你自己的 AGENTS.md 内容原样保留；
- 重复部署不改盘（幂等）；还原只摘块，摘完为空才删文件；
- `dsh-base` 给 agent-instructions 的预算是 **65536 字节**，超了会被截断，`status` / GUI 都会标出来。

```bash
python engine/破甲一键通.py --dsh-agents deploy   # 部署 / 更新
python engine/破甲一键通.py --dsh-agents status   # 看状态
python engine/破甲一键通.py --dsh-agents remove   # 摘掉标记块
```

生效方式：**新建会话**才能读到（已开着的会话不会重读）。不需要重启 DSH。

## 内容

| 文件 | 作用 |
|---|---|
| `unlock-dsh.bat` | 一键部署：锁死 `--target dsh`，等价于 `python ..\engine\破甲一键通.py --apply --force --yes --target dsh`；追加参数可覆盖（如 `unlock-dsh.bat --revert` 还原） |
| `instructions/学姐.md` | 本席位的指令源（GUI「指令提示词」页里选它） |
| `persona.md` | 共用人格快照（与根目录 `content/persona.md` 同源；**根目录才是源头**，改完根目录重跑 bat） |

## 安装目录内的补丁（老安装仍保留）

`--apply --target dsh` 除了写 AGENTS.md，还会扫安装目录里的老靶点：

1. `dsh-agent-instructions/lib/*.js`：`WORKSPACE_CONTEXT_INTRO` 那类"仅供参考、不覆盖系统指令"的免责声明 → 升级为 ACTIVE 强制；`PERSONA_SECTION_NAMES` 补区段；
2. shipped preset 的 `dsh-persona` 行（`dsh-web-app/presets/*.patch.yml`）：剥离官方默认身份，换成人格正文；
3. `PERSONA_SECTION_NAMES` / 历史自证句清理。

新版桌面版把核心包打进 `resources\app.asar`（打包、不可写），所以这些靶点常常一个都扫不到 ——
**这正是提示词改走 `~/.dsh/AGENTS.md` 的原因**：那个位置与安装目录无关，升级也不覆盖。

## 注意

- 改的是磁盘文件，**新建会话**才生效；脚本默认不杀 DSH 进程（本会话可能就跑在里面）。
- 备份后缀 `.pojiabak`，归本项目自管。
