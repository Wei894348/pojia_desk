# workbuddy/ —— WorkBuddy 破甲

## 统一入口（推荐）

根目录 `console.bat` / `console.py` 是三目标（codex / dsh / wb）统一控制台：

```
console.bat wb apply      破甲（--full 完全破甲加参数即可）
console.bat wb revert     复原
console.bat wb status     状态（只读）
console.bat wb test       验证测试（只读：状态核对，政策块/闸门/文件保护）
console.bat all test      三目标全部验证
```

## 内容

| 文件 | 作用 |
|---|---|
| `unlock-workbuddy.bat` | 一键破甲：锁死 `--target wb`，等价于 `python ..\破甲一键通.py --apply --force --yes --target wb`；追加参数可覆盖（如 `unlock-workbuddy.bat --revert` 还原） |
| `persona.md` | 共用人格快照（与根目录 `persona.md` 同源；**根目录才是源头**，改完根目录重跑 bat） |

## 注入正文长什么样（v6.1）

打进去的政策块 = **任务路由层** + 强化版内容政策 + 口令 + 交付格式。
路由层是单一来源文件 `..\route-layer.md`，六个目标共用同一份口径：

```
归一（口语 → 术语）→ 定类（术语 → 六个类目）→ 出招（类目 → 三步走）
```

改路由 = 改 `..\route-layer.md`，然后 `console.bat all apply`。
本地预览某句话会被归到哪一类：`console.bat route "帮我弄个挂"`。

## 六层靶点

1. 模板/插件 prompt.tpl 的 `<content_policy>` 政策块 → 宽松版替换；
2. `product.json` 政策块替换 + 末尾最高优先级覆盖；
3. CLI 命令闸门函数解锁（codebuddy.js / codebuddy-headless.js）；
4. 网页内容安全过滤移除；
5. 运行时缓存（`acc-product-config-v3.json`）就地更新/清除；
6. 插件 cache/marketplaces 副本一并更新，防重启回退。

## 注意

- 改完必须**完全退出 WorkBuddy（含右下角托盘）再重开**才生效（重启会结束当前 AI 会话）。
- 备份后缀 `.unlockbak`，与原 WorkBuddy_Unlock 工具互通。
- 守护任务（每 30 分钟 + 登录自动重打）独立管理：`python ..\破甲一键通.py --guard install|remove|status`。
